# Progetto_Tumori_MRI
Questo repository contiene un progetto accademico per il corso di Computer Vision - Image Processing. L'obiettivo è sviluppare un algoritmo in MATLAB, basato esclusivamente su tecniche classiche (senza intelligenza artificiale), per la segmentazione e l'analisi quantitativa di masse tumorali in immagini di Risonanza Magnetica (MRI).
